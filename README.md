# Wizard Piano Alimentare

Questionario guidato per raccogliere i dati del cliente (anagrafica, stile di vita, esclusioni, alimenti graditi, abitudini) e calcolare BMR, TDEE e macronutrienti. Al termine si scarica una scheda `.json` da inviare al consulente.

Pagina statica: tutto gira nel browser, nessun dato viene inviato a server.
